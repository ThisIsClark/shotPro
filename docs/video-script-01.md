# 第 1 条视频脚本 — CapCut 手机版 v2

**总时长：** 15 秒 | **画幅：** 9:16 竖屏 | **语言：** 英文（视频内文字）| **工具：** CapCut（手机）

---

## v2 相比原版改了什么

- **补上了缺失的转场（3.5–4.5s）**：投篮片段 visibly 缩进 formrefine.ai 上传区（"Click or drag video here"），再交叉溶解到分析结果。这一拍原本缺失——它让画面读作"我的球**进了** formrefine"，而不是"投篮，然后突然冒出一张截图"。
- **加了 formrefine.ai 常驻水印**：覆盖整个分析段（4.5–8s），让品牌在结果展示期间持续可见。
- **加了转场音效设计**（whoosh → tick → riser → chime）。声音比画面更能卖"工具接管了"这一拍，并且在静音自动播放下也成立。
- 时间码整体后移约 0.5s 来容纳转场；总时长仍为 15s。

## 素材清单

### A. 从 formrefine.ai 截图（现在电脑上截）

- [ ] **上传页** —— 带 "Click or drag video here" 虚线 drop zone 那个界面。如果 UI 外壳里有 formrefine logo/wordmark，保留可见。*(用作转场背景，3.5–4.5s。)*
- [ ] **分析：四宫格关键帧** —— 4 个阶段关键帧同框那张截图（Preparation / Lifting / Release / Follow-through）。*(4.5–6.5s。)*
- [ ] **分析：Release 帧特写** —— 带角度标注的 Release 关键帧放大版。*(可选但推荐——比在 CapCut 里捏拉放大干净。6–6.5s。)*
- [ ] **发力脱节检测卡** —— 带红色 ⚠️ 标签、标出"起球停顿 / 发力脱节"的截图。**全片证据核心。** *(6.5–8s。)*

### B. 品牌素材

- [ ] **formrefine.ai wordmark / logo** —— 透明 PNG 最佳。*(4.5–8s 的水印 + 14–15s 的 CTA。)*
  - 零成本替代：不用素材，CapCut 里直接打文字层 `formrefine.ai`，透明度 70%。

### C. 投篮实拍（原始视频）

- [ ] **"Before" 片段** —— 约 4 秒以上，"看着对、感觉不对"那个球。同一段会先全屏播（1–3.5s），再做缩入转场（3.5–4s），所以**多留一点尾巴**。
- [ ] **"After" 片段** —— 约 3 秒，改进后更顺的那个。*(11–14s。)*

### D. 音频

- [ ] **背景音乐** —— 篮球 / hype 节奏。*(CapCut → 音频 → 音乐 → 搜 "basketball" / "hype" / "beat"。)*
- [ ] **转场音效** —— whoosh + tick + chime。*(CapCut → 音频 → 音效 → 搜 "whoosh" / "tick" / "pop" / "chime"。)*

### 本脚本不用
- 17 连中素材 —— 原 CapCut 结构里没有连中这一拍。这版跳过。

## 完整分镜 + CapCut 操作步骤

### 0–1s | 黑屏 + 钩子文字

1. 点 **+** → 新建项目 → 选 9:16
2. 点 **背景** → 纯黑色，拖到 0–1 秒
3. 点 **文字** → 添加文字 → 输入 `Your shot feels off.`
4. 字体选 **Impact** 或 **Montserrat Bold**，字号拉到最大
5. 颜色白色，点 **描边** → 黑色描边，粗细 5–8
6. 居中，长度 0–1 秒
7. 点文字 → **动画** → **入场** → 选 **弹跳** 或 **放大弹出**

### 1–3.5s | 投篮实拍（全屏）—— *从原来的 1–4s 缩短，给转场腾位置*

1. 点 **+** → 导入 "before" 投篮片段
2. 拖到 1–3.5s
3. 在 ~2.5s 处 → **变速** → **0.3x**（出手瞬间慢动作）
4. 点 **滤镜** → **冷调** 类别 → 选 "Frost" 或 "Cool"，强度 ~60%
5. 点 **文字** → 输入 `Not weak. Just... disconnected.`
6. 白色字，中号，加黑色描边；放画面底部；下面垫一个 50% 透明度黑色矩形（**形状** → 矩形 → 黑色 → 透明度 50%）

### 3.5–4.5s | 转场 —— 片段缩进 formrefine（新增的关键拍）

这一拍就是修复"没展示出经过 formrefine"问题的关键。

1. 在 3.5s 处**分割**投篮轨。前半段（1–3.5s）保持全屏。
2. 从 3.5s 起，**主轨**换成 **formrefine 上传页截图**（铺满屏）。现在画面是工具界面。
3. 把刚分割下来的投篮后半段（分割点之后约 0.5s）作为**画中画**叠上去，起始 scale 100%、居中。
4. 给画中画打关键帧：
   - 3.5s：scale 100%，位置居中
   - 4.0s：scale ~30%，位置精确移到 "Click or drag video here" 虚线框中心
   - 插值用 ease-in-out，落点轻微 overshoot 到 ~28% 再回弹到 30%，有"吸附感"
5. 画中画加一层淡阴影（**样式** → 阴影），让它读起来是"贴在 UI 里的视频"，不是飘着。
6. 4.0s 落定那一刻：加 scale-pop（1.0 → 1.05 → 1.0，约 4 帧）+ 一声 **tick 音效**。
7. 4.0–4.5s：画中画**交叉溶解**到**四宫格关键帧截图**。中间压 0.3s 一个 `Analyzing…` 文字或细进度环——"工具在干活"那一拍。
8. 整拍的音效设计：
   - 3.5s：**whoosh**（片段被吸走）
   - 4.0s：**tick**（落进框里）
   - 4.0–4.5s：上升的 **riser**（处理中）
   - 4.5s：干净双音 **chime**（结果出现）

### 4.5–6.5s | 分析展示 —— 四宫格关键帧

1. 主轨 = 四宫格截图，4.5–6.5s
2. **动画** → **入场** → **上滑**
3. 在 ~6s 处：**分割**，放大到 Release 帧（或直接硬切到提前截好的 Release 特写截图）
4. **常驻水印**：加画中画文字层 `formrefine.ai`（或透明 logo），透明度 70%，钉在右上角，长度 4.5–8s

### 6.5–8s | 发力脱节截图

1. 导入 ⚠️ 发力脱节截图，6.5–8s
2. **动画** → **入场** → 选 **放大** 或 **闪烁**，强调红色标签

### 8–11s | 原理解释

保持 ⚠️ 截图作背景。逐行加文字（每行单独文字轨道）：

- 8s：`Legs still bending` —— 白色，中号，画面左侧
- 9s：`↑` —— 黄色，大号，画面中间
- 9.5s：`Arm already rising` —— 白色，中号，画面右侧
- 10s：`= Power gap` —— 红色，大号加粗，画面居中

每行：**动画** → **入场** → **逐字弹出** 或 **淡入**

### 11–12.5s | 转折 -- 改进后投篮（压缩到 1.5s 给结尾让位）

1. 点 **+** -> 导入 "after" 投篮片段，11–12.5s
2. **不加滤镜**（暖色调恢复）
3. **变速** -> 1.5x，放 2–3 个改进镜头快剪
4. 点 **文字** -> 输入 `Same power. Better timing = more makes.`
5. 白色大字，居中，黑色描边
6. **动画** -> **入场** -> **逐词弹出**（每个词依次出现）

### 12.5–15.0s | 结尾卡（两屏，复用 formrefine.ai 统一品牌卡）

完整 SOP 见 `docs/brand.md`。下面是 CapCut 操作要点。

**Screen 1 - tagline 屏（12.5–13.7s）**

1. 主轨放深海军蓝纯色图（#0A1A2F），12.5–15.0s（**贯穿两屏不断**）
2. **文字** -> 添加 -> 输入 `Feel the difference`（第一行）
3. 字体 **Montserrat Regular**，字号占画面宽 ~55–60%，白色透明度 90%
4. 再加一行文字 `you can't see.`，紧接第一行下方
5. 两行都加 **淡入** 0.4s；第二行比第一行延迟 0.25s（压轴落定）
6. 两行在 13.5s 加 **淡出** 0.2s（让位给 Screen 2）
7. 12.5s 加一声低频 pad/sustain 长音，音量 40%

**Screen 2 - wordmark 屏（13.7–15.0s）**

8. **文字** -> 添加 -> 输入 `formrefine.ai`
9. 字体 **Montserrat SemiBold**（比 tagline 粗一档），字号占画面宽 ~35–40%，纯白
10. 位置垂直居中，长度 13.7–15.0s
11. **入场动画** -> **淡入** 0.3s（13.7s 起，比 tagline 出场晚 0.1s，形成接力）
12. **下划线动画（可选，加分项）**：贴纸搜 "line" 或形状->矩形拉扁->白色，透明度 80%，放 wordmark 正下方；关键帧 13.9s 宽度 30% 起点 -> 14.5s 宽度 100% 终点（绘制签名动作）
13. **chime 音效**拖到 13.7s（双音低->高），第二个音对齐 14.5s（下划线画完）
14. BGM 在 14.5s 加 **淡出** 0.5s，让 chime 成为最后被听到的声音

**简化版（赶时间）**：省掉下划线动画和双行延迟，tagline 一次性输完两行淡入，wordmark 淡入，一个 chime 在 13.7s，BGM 14.5s 淡出。3 分钟搞定。

15. 这一段单独渲染成 2.5s 片段，后续每条视频直接拼接

### 配乐

1. **音频** → **音乐** → 搜 "basketball" / "hype" → 拖到整条时间轴
2. 音量 30–40%
3. 0s 和 15s 处各加 0.5s **淡入/淡出**
4. 转场音效（whoosh/tick/chime）放在 3.5–4.5s 拍上——这几个音效音量略高于 BGM
