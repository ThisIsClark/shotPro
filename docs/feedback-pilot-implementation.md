# 反馈与复测试点：本地实现与验证

日期：2026-11-02

## 使用路径

1. 在 `/app` 登录并上传视频。选中 **Keep this video privately for feedback and follow-up**，为后续复盘保存原视频。
2. 自动分析完成后，从结果页顶部 **Get training feedback** 进入，填写目标、场景、困扰并申请人工反馈。
3. 顶部 **Training** 展示按主题归组的训练记录。管理员在同一入口查看已申请的记录。
4. 管理员打开 **Reviewer workspace**，查看视频、慢放、定位证据、截取并命名关键帧，填写训练重点、具体练习、复测条件、检查标准和反馈者身份；先保存草稿，再发布。
5. 用户在训练卡里查看建议，通过 **Submit a follow-up** 提交练习记录与视频。复测后显示前次视频、当时的反馈版本以及本次记录。
6. 管理员为复测视频发布下一轮建议。已提交复测的原记录提供 **View submitted follow-up**，避免重复提交。
7. 分享链接只展示指定已发布版本和授权视频。用户可以撤销所有相关链接。

旧分析如果没有原视频，会提示补传。补传后的素材不会直接套用旧角度数据；管理员可重新运行自动分析，或直接人工查看。

## 与原有流程的边界

- 原有自动分析、球星模板、曲线、历史和导出继续保留。
- 目标和场景在申请人工反馈时填写，普通分析不强制增加表单步骤。
- 反馈页面的原始自动观察与人工结论分开保存；人工关键帧修正不会覆盖旧分析文件。
- 新增复测复用 `AnalysisService`，通过 `AnalysisConfig.output_dir` 将文件直接写到私有目录，不创建公开 `/results` 地址。
- 普通自动分析计费不变。申请人工反馈不重复扣分析积分；首次受邀反馈附带一次复测，复测不消耗普通积分。
- 管理员可在 Training → Manage pilot access 中输入用户展示的 Pilot ID 分配首次反馈次数。管理员自身可操作演示流程。
- 首版以英文文案为主；部分入口随当前语言显示中文，尚未完成新工作区全部文案的双语覆盖。

## 持久化选择与部署限制

本次实现使用标准库 SQLite + 私有本地媒体目录，而不是直接修改线上 Supabase 表。默认目录：`data/feedback/`，由 `FEEDBACK_DIR` 配置。

- `feedback.sqlite3` 存储用户归属、试点资格、训练关系、草稿、不可变发布版本、分享 token hash。
- 每个任务独立目录保存原片、可选的浏览器兼容播放副本、自动与人工关键帧。
- 数据不依赖进程内存，服务器重启后可读取。原有“仅保留十个任务”的清理不会触碰这个目录。
- 重启时将中断的分析标为可重试，释放未完成上传的临时目录，并重试清理已删除主题的媒体。
- 面向**单主机试点**。部署必须挂载持久磁盘并备份 SQLite 和媒体目录；不能直接依赖 HF 临时容器文件系统，也不适合多副本共享写入。大规模部署前再迁移数据库及对象存储。
- 本次没有部署，没有更改线上支付配置或 Supabase 结构。

## 媒体和权限

- 业务 API 使用现有登录 Bearer token，资源归属由后端核验；只有管理员可编辑/发布。
- 视频请求使用短时 HttpOnly 媒体 Cookie，支持 Range，且不会把登录令牌放进视频 URL。
- 分享 token 放在链接 fragment，通过 POST 换取仅限对应版本媒体的 Cookie；访问日志不记录链接 token。
- 每次分享媒体请求都会检查撤销状态。已下载的内容无法远程收回。
- 退出登录会清除媒体 Cookie。
- 删除 Training 主题关闭分享并删除私有副本。**原有自动分析的公开关键帧/导出不属于这份私有副本**，撤销新分享不会撤销旧图片链接；页面也明确区分这两类数据。
- 旧分析删除接口对尚未删除的关联训练记录返回冲突，避免误删反馈依赖。先在 Training 删除主题，再删除旧分析。

## 验证方式

隔离接口测试（临时 SQLite、合成视频、模拟分析后台，不操作真实用户数据）：

```bash
PYTHONWARNINGS=ignore venv/bin/python -m unittest discover -s tests/feedback -v
venv/bin/python test_core.py
venv/bin/python test_import.py
```

真实本地端到端验证：

```bash
PYTHONWARNINGS=ignore venv/bin/python scripts/feedback_smoke.py
```

此脚本只连接 `127.0.0.1:8000`，使用本地管理员和 `modelVideo/reddit1009.mov`，创建明确标记为 **Local QA** 的演示记录，不代表对视频的真实教练判断。会验证普通分析、人工反馈发布、分享播放与撤销、复测分析及版本关联。结果写入 `artifacts/feedback-qa/smoke-result.json`。

演示中复测重复使用同一视频，仅验证软件流程，不能视为训练改善证据。记录保留在本地 Training，便于直接查看效果。

## 首版尚未覆盖

- 自动邮件或私信通知、教练账号分配与教练市场。
- 专业建议的自动生成和有效性验证；反馈质量仍取决于反馈者。
- 自动同步双视频、完整曲线的自我前后对比；目前支持独立播放、事件定位与关键帧查看。
- 后台分布式任务队列；进程中断后由管理员重试。
- 原片保留，另用 FFmpeg 生成浏览器兼容的播放副本（Docker 已加入依赖）。本地若无 FFmpeg 或转换失败会回退原片；不能假设所有 MOV 编码都被 Chrome 支持。
