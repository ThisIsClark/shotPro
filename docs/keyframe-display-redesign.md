# 关键帧展示方案（修订版）

## 问题

当前方案把 8 个关键帧分散在多个地方：
- 原有 4 帧藏在协调检测卡片里（用户不一定注意到）
- 新增 4 帧在曲线图上用竖线标注（太小，不够直观）
- 时间轴条是独立的缩略图条（和曲线图割裂）
- 模板对比只在选了模板时才出现，且是独立的对比视图

8 个关键帧 + 模板对比，如果继续分散展示会越来越乱。需要一个统一的展示方式。

## 方案：关键帧卡片 + 内嵌模板对比

### 核心思路

把所有关键帧统一到一个 **"关键帧"section**，每个关键帧是一张卡片。如果选了模板，卡片内直接展示左右对比。

### 交互细节

1. **卡片网格**：2 列（移动端）或 4 列（桌面端），每张卡片显示：
   - 关键帧图片（带骨骼标注）
   - 阶段名称
   - 核心角度值（该帧最关键的角度，如最低蹲点显示膝盖角度）
   - 如果有模板对比：角度差异色标（✓绿色 / △黄色 / ✗红色）

2. **点击卡片**：
   - 无模板：lightbox 放大
   - 有模板：卡片展开为左右对比视图（inline，不用弹窗），再点收起

3. **曲线图联动**：
   - 曲线图上的竖线标记保留（彩色实线 + 标签）
   - 点击曲线图竖线 → 滚动到对应的关键帧卡片并高亮
   - 点击关键帧卡片 → 曲线图上对应竖线闪烁

4. **协调检测卡片**：保持不变，仍然用原来的 4 帧做手脚同步/发力脱节检测展示。但不再作为关键帧的主要展示位置。

### 每个关键帧显示的核心角度

| 关键帧 | 核心角度 | 说明 |
|--------|----------|------|
| 最低蹲点 | 膝盖角度 | 这个帧的意义就是膝盖弯曲最深 |
| 沉球点 | 膝盖角度 | 手脚同步的基准点 |
| 最紧折叠点 | 肘部角度 | 这个帧的意义就是肘部折叠最紧 |
| 手上升后 | 膝盖角度 | 检测手快脚慢的对比帧 |
| 手腕最高点 | 肘部角度 | 出手瞬间肘部伸展程度 |
| 最高持球点 | 肘部角度 + 膝盖角度 | 发力脱节检测的关键帧 |
| 出手点 | 肘部角度 | 出手时肘部状态 |
| 跟随定型点 | 肘部角度 | 跟随动作定型时的手臂状态 |

### 模板对比的兼容

- 旧模板只有 4 帧（sync_frame_1/2, max_hold_frame, release_frame），新增的 4 帧没有模板对应帧
- 卡片上：有模板帧的显示差异色标，没有的只显示用户自己的角度
- 展开对比时：没有模板帧的那一侧显示"模板无此阶段"

### 实现要点

1. **重新启用 keyFramesSection**：把 `display: none` 改为根据结果显示
2. **重写 keyFrames grid**：从简单的图片网格改为带角度信息和模板对比的卡片
3. **曲线图竖线**：保留，但改为点击后滚动到对应卡片
4. **时间轴条**：去掉，改为曲线图竖线 + 卡片网格的联动
5. **模板对比**：不再用单独的 `renderTemplateComparison`，而是内嵌到每张卡片中
