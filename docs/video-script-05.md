# 第 5 条视频脚本 - 球星模板对比功能（转化导向）

**总时长：** 25–35 秒\
**画幅：** 9:16 竖屏\
**语言：** 英文字幕 + on-screen text\
**形式：** 关键帧/截图对比为主 + 2–3 秒真实录屏点缀\
**目标：** 吸引用户体验球星模板对比功能，建立付费价值感\

---

## 为什么用截图对比而不是纯录屏

球星模板对比功能的核心价值不是「怎么操作」，而是**「你能看到自己与职业球员的数据差距」**。

| 维度 | 纯录屏 | 截图对比 |
|------|--------|---------|
| 观众心理 | "这 app 怎么用" | "我和库里差多少" |
| 转化驱动力 | 弱 | 强（好奇 + 渴望） |
| 高级感/付费感 | 像免费工具 | 像 premium 功能 |
| 视觉冲击力 | 中 | 强 |

> 录屏适合讲「怎么用」，截图对比适合讲「为什么值得用」。

### 视觉细节

1. **转场：感觉不对浮现库里（本片记忆点，用同一条投篮素材）**
   - **不需要另拍发呆素材**：直接用投篮主视频球进网后那 2 秒（你投篮后自然站立，本来就是天然的"放空"画面）
   - 可选：把球进网后那 2 秒**慢放 0.5x**，制造"愣一下"的时间凝滞感——比演表情好实现，且更有戏
   - 库里投篮画面从画面中心淡入浮现：像回忆/想象直接在脑中显现，叠在你画面上方（你还在底下，库里半透明）
   - opacity 从 0 -> 50%，叠高斯模糊（能看出是库里投篮、但不够清晰），像梦境/回忆
   - 加一点柔光/光晕强化"脑海浮现感"
   - 音效：浮现时配空灵混响（whoosh + reverb）——光靠画面不够，音效是"想象感"的关键
   - 这 2 秒留白，不加字幕
   - 接 hook 时库里画面渐变清晰 + 放大（模糊归零、opacity 拉满占满屏），底下你的画面被盖住，从想象落到现实

2. **Split screen 布局**
   - 左：你的 release 帧
   - 右：Curry 模板 release 帧
   - 中间：VS 或分隔线
   - 底部：各自角度数字

3. **角度数字动画**
   - 用 CapCut 「关键帧」让数字从 0 涨到真实值
   - 你的数字用黄色 `#feca57`
   - 球星数字用蓝色 `#48dbfb`

4. **曲线对比图**
   - 你的曲线：实线，黄色 `#feca57`
   - 球星曲线：虚线，蓝色 `#48dbfb`
   - 背景 phase 色带保留

5. **录屏点缀**
   - 只保留最有信息量的 2 秒：鼠标点击模板下拉 -> 结果出现
   - 不要放上传、等待、分析过程

## 转化设计要点

1. **不要讲操作**：不要展示上传、等待、设置
2. **突出结果**：让观众看到"我能得到什么"
3. **具体数字**：用真实角度差，不要说 "better" 或 "worse"
4. **制造渴望**：用 "Shoot like Curry. Take over your league." 而不是 "Analyze your shot"
5. **降低门槛**：CTA 用 "Free to try" 或 "See your gap"，不要直接说 "Pay"

## CapCut 制作指导（手机版）

> 按 CapCut 手机版操作写。桌面版功能一一对应，按钮位置略有不同。

### 一、开工程

1. 打开 CapCut ->「新建项目」-> 先导入你的投篮主视频放主轨
2. 在主轨空白处点「比例」-> 选 **9:16**（竖屏）
3. 点「背景」-> 纯黑或「模糊」填充，保证竖屏画幅满屏

### 二、拍前素材清单（先备齐再开工）

| # | 素材 | 怎么搞 |
|---|------|--------|
| 1 | 你投篮进球的侧面视频 | 找人帮拍，侧面、全身入镜、光线清楚。主素材，release 帧也从这抽，**转场也复用这条**（球进网后那 2 秒） |
| 2 | 库里投篮画面 | 见下方"库里素材处理策略" |
| 3 | 产品里的曲线对比截图 | app 里跑一次你和库里模板的对比，把曲线图截图存下来 |
| 4 | split screen 用的关键帧图 | 你的 release 帧（从素材 1 截图）+ 库里模板的 release 帧图 |
| 5 | 录屏 | 手机录屏：选模板 -> 对比结果出现，只留 2 秒高光 |
| 6 | outro 卡 | 系列统一的那张 formrefine.ai 结尾卡 |

> 转场不再需要单独的"发呆"素材——直接用素材 1 的后半段。

### 三、库里素材处理策略（重要，先决定）

转场和 split screen 对库里素材的要求不一样，直接决定版权风险：

- **转场那段（0:03–0:08，要求模糊）**：可用真实库里投篮视频，做高斯模糊处理。模糊 + 短暂，版权风险低，且本来转场就要模糊质感，刚好契合。
- **split screen 那段（0:11+，要求清晰）**：**不要用 NBA 比赛清晰画面**，会被 TikTok / IG 版权检测限流。改用**你产品里库里模板的 release 关键帧图**（素材 4）——这是你自己的产品资产，零版权风险，且逻辑上呼应"用我们的库里模板对比"。

一句话：**库里"想象"用真实视频模糊处理，库里"对比"用产品模板图。** 既保住想象感，又躲开版权。

### 四、分镜逐段操作

**0:00–0:03 球进框**

1. 主轨是你的投篮视频。拖时间轴到起跳前，点「分割」，删掉前面
2. 拖到球进网后**多留 2 秒**（别剪太干净，这 2 秒是转场要用的画面），点「分割」，保留约 5 秒（进球 3 秒 + 留 2 秒转场用）
3. 保留原声（球进网唰声，不要静音）
4.「文字」->「新建文本」-> 输入 `This went in.`，样式选白色无衬线，放画面下 1/3

**0:03–0:05 感觉不对浮现库里（转场，本片记忆点，复用同一条素材）**

1. 0:03 起**就是素材 1 球进网后的那 2 秒**——你的投篮视频继续播，你自然站立，不需另拍
2. 可选：选中这 2 秒 ->「变速」-> **0.5x**，制造"愣一下"的时间凝滞感（慢放后这段会变成 4 秒，再「分割」裁回 2 秒）。觉得麻烦可跳过，原速也成立
3. 点「画中画」->「新增画中画」-> 导入库里视频，叠在你画面上方，库里层**居中**放置（不从某一侧飞入，像在脑中直接显现）
4. 选中库里层，点底部「菱形」关键帧图标：
   - 在 0:03 起点打关键帧，「不透明度」设 **0%**
   - 拖到 0:05，「不透明度」设 **50%**
5. 给库里层加模糊：点「特效」->「画面特效」->「基础」->「模糊」，加好后点「作用对象」选库里那一层，强度调到 **能看出是库里但不够清晰**（约 30–40）
6. 加柔光：「特效」->「画面特效」->「光效」->「光晕」，作用对象选库里层
7. 音效：点「音频」->「音效」-> 搜 `whoosh`，拖到 0:03 起点处；再叠一个 `reverb` 空灵感。这是想象感的关键，光靠画面不够
8. 这 2 秒**不加字幕**

**0:05–0:08 库里变清晰放大**

紧接上一段库里层，继续打关键帧平滑过渡：

1. 不透明度：0:05 处 50% -> 0:08 处 **100%**
2. 模糊强度：0:05 处 30 -> 0:08 处 **0**（选中模糊特效层打关键帧调强度，平滑消失）
3. 缩放 scale：0:05 处 1.0 -> 0:08 处 **1.2**，让库里占满屏
4. 这下"模糊->清晰 + 放大"就是"想象->现实"，库里占满屏后底下你的画面被完全盖住
5. 加文字 `Now picture Curry's.`，在变清晰过程中出现

**0:08–0:11 库里定格 hook**

1. 拖到库里最帅的投篮姿势那一帧，点「定格」（CapCut 会生成约 3 秒静帧），删掉定格前后多余
2. 给静帧加缓慢 zoom：起始打关键帧 scale 1.0，结尾 1.1，画面不死
3. 文字 `Want that shot? The kind nobody can guard?`

**0:11–0:15 split screen**

1. 主轨放一张黑底（纯色）4 秒
2.「画中画」导入你的 release 帧图，双指缩到约 **48%**，拖到画面左半
3. 再「新增画中画」导入库里模板 release 帧图，缩到 48%，拖到画面右半
4. 中间「贴纸」搜 `VS` 或用文字 `VS`
5. 文字 `See where you actually stand.`

**0:15–0:19 角度数字弹出**

1. split screen 画面不切，继续
2.「文字」->「新建文本」：左下输入你的角度（如 `138°`），颜色黄 `#feca57`；右下输入库里角度（如 `149°`），颜色蓝 `#48dbfb`
3. 数字动画：选中文字 ->「动画」->「入场」选**放大弹入**，时长 0.5 秒。你的数字先出，库里数字错开 0.3 秒后出
4. 顶部加一行 `Your release: 138° / Curry: 149°`
5. 数值用你实际分析结果，别编

> CapCut 做"数字从 0 滚动到真实值"较麻烦（要逐帧改文本或找计数模板），用「放大弹入」动画直接弹最终值，视觉冲击够、操作简单，推荐这么干。

**0:19–0:24 曲线对比图**

1. 主轨接上曲线对比截图（素材 3），约 5 秒
2. 加 Ken Burns：选中截图打关键帧，起始 scale 1.0 位移偏左，结尾 scale 1.1 位移偏右，缓慢平移让截图不呆板
3. 文字 `The gap is real. Now close it.`

**0:24–0:27 录屏**

1. 导入录屏（素材 5），「分割」只留"点模板 -> 结果出现"那 2 秒，前后多余全删
2. 选中 ->「变速」-> **1.5x**，节奏更紧
3. 文字 `Pick a star. See your gap.`

**0:27–0:32 outro 卡**

1. 导入 outro 卡（素材 6），5 秒
2. 卡片本身已带 formrefine.ai 字样则不再加字；没有则加文字 `Shoot like Curry. Take over your league. formrefine.ai`

### 五、全局收尾

- **配乐**：「音频」->「音乐」搜 `lofi hiphop instrumental`，音量调到 **-8dB** 左右；转场 whoosh 处用关键帧把配乐音量瞬时压低，让音效突出
- **音效统一**：转场浮现处固定用 whoosh + reverb，全片只用这一种转场音效，形成记忆点
- **节奏检查**：每 2–4 秒一个画面变化，任何画面别停超 4 秒。整片导出前从头看一遍，卡的地方就是观众划走的地方
- **导出**：1080P、30fps、9:16
