# formrefine.ai Brand Assets

品牌资产统一引用源。视频结尾、网站、社媒、logo lockup 都从这里取，保证一致性。

---

## 主 Slogan（品牌口号）

> **When it feels off, find out why.**

**用途：** 网站 hero、logo lockup、社媒简介、产品介绍首句。
**为什么是这句：**
- 直接命名产品核心用户痛点 -- "看着对但感觉不对"（所有打过球的人都有的体感）。
- 同时占了"模糊体感"和"工具给的答案"两半。
- 是动作邀请（find out why），不是静态陈述，比 "analyze your shot" 具体得多。
- 从用户嘴里的话变体而来，不是营销腔。

## SB7 品牌故事脚本

基于 Donald Miller《你的顾客需要一个好故事》StoryBrand 7 框架，落地页与视频通用的叙事顺序。品牌故事的统一叙事源，所有对外文案（网站、视频、社媒、广告）从这里取素材。

**叙事顺序（落地页 + 视频统一）：** Hero 命名问题 -> Failure 代价前置 -> Guide 向导 -> Plan 计划 -> Proof 证据 -> Success 愿景。Failure 提前到第二拍做钩子，Proof 独立成段量化"看不见的差距"。

### 1. HERO - 命名问题（融合 Character + Problem，feels off + feels right 双向）

**SB7 角色：** 让英雄说"对，这就是我"。命名问题 = 同时承担 Character（你是谁）和 Problem（你有什么问题）。

> **英雄：** 一个认真练投篮的人。他记得**那一次**--球还没离手，他就知道会进。发力顺、节奏对，"感觉"回来了。但从那以后他一直在找它，大多数时候只剩下"感觉不对"--发力不顺、节奏脱节，说不清问题在哪。
>
> **命名问题（双向）：**
> - 你追的那一次：`You know that one shot. The one that felt right.`（feels right -- 你拥有过，又丢了）
> - 你卡住的每一天：`Your shot feels off. You've put in the reps. You know something's wrong. You just can't see it.`（feels off -- 你知道有问题，但看不见）

**关键：** 英雄不是"不会投篮的新手"，而是"已经能投但卡在瓶颈的人"。这决定了整个故事的语气--不是教你从零开始，而是帮你**找回你曾经拥有过的那一次**。`feels right` 是你最好的那一次（黄金一投），`feels off` 是你被卡住的日常，两者互为对照。痛点从"感觉不对"升级为"丢失了感觉对的状态"--失去过比从没拥有过更痛，也更有行动力。`You just can't see it` 是哲学层--不是你的错，是眼睛的局限；"感觉"是你投篮里最真实也最抓不住的东西，看不见的东西重复不了。

**CTA（Hero）：** `See your gap -> formrefine.ai`（过渡 CTA，结果导向不是功能描述）

### 2. FAILURE - 失败的代价（提前到第二拍做钩子）

**SB7 角色：** 温和的紧迫感。不恐吓，但让用户意识到"不行动有成本"。短视频里代价比问题陈述更抓完播，所以提前。

> **1,000 reps with the same flaw isn't practice. It's permanent.**
>
> 带着同一个缺陷练 1000 次，不是练习，是定型。每一次没修的出手，都在加深错误的肌肉记忆--离你那次"感觉对了"越来越远。你看不见，就修不了。

**语气：** 温和的紧迫感，不是恐吓。是"你值得更好的"，不是"你会完蛋"。可以配计数器动画（1... 100... 1000...）增强冲击感。

### 3. GUIDE - 向导（共情 + 权威）

**SB7 角色：** 让用户信任你。先共情（我懂你），再权威（我能帮你）。

| | 共情 | 权威 |
|--|------|------|
| 说什么 | "You've felt it. That one shot that felt right. And every shot since that didn't. We know that 'feel' isn't magic--it's a pattern." | "We see what your eyes can't. Frame by frame. Degree by degree. Every joint, every phase, every timing gap - measured and mapped." |
| 语气 | 我懂你 | 我能帮你 |
| 证据 | 命名了你的感受 | 逐帧角度数据 + 曲线对比 |

**向导定位：** formrefine 不是教练，是教练的眼睛。教练告诉你"手抬高点"，formrefine 告诉你"你的肘在 release 阶段比库里晚 12°，比你那次最好的出手晚 9°"。前者是模糊指令，后者是精确诊断。**核心动作是把"感觉"量化**--把你那次"感觉对了"的出手变成一条曲线、一个数字，让你之后的每一次都能拿来对比。"感觉"不再是你抓不住的玄学，而是你能看见、能重复的东西。共情侧（"你也经历过"）在视频里常并入 Hero 段，Guide 段重点打权威。

### 4. PLAN - 计划（三步）

**SB7 角色：** 降低决策焦虑。让用户觉得"这很简单，我能做"。

```
1. Film one shot            -> 拍一个投篮（一段视频，侧面角度，任何手机）
2. See what your eyes miss  -> 看到眼睛看不到的（每关节角度映射 + 时序差距测量）
3. Fix the gap              -> 修掉差距（精确知道该改什么。然后投进更多）
```

**关键：** 每一步都是用户视角的动作，不是功能描述。不是"AI 分析你的投篮"，而是"See the gap"。

**进阶（个人基准模板）：** 当你找到一次"感觉对了"的出手，把它存成你的**个人基准模板**。之后每一次投篮，都拿来和它对比--不是对标别人，是找回你自己最好的那次。

### 5. PROOF - 证据（独立成段，量化"看不见的差距"）

**SB7 角色：** 证明向导的权威。不是"功能展示"，是"证据"。把 Hero/Guide 段"看不见的差距"量化成曲线和度数--这是 formrefine 的核心卖点，也是 `you can't see` 这个 tagline 的兑现。

> **The gap is real. And it's measurable.**
>
> 差距是真实的。而且可测量。你的眼睛看到一个投篮，我们看到 6 个关节角度的时序、断点、决定进球与否的看不见的差距。

**证据形式（两种参照系）：**
- **对标球星**：你的实线 + 球星虚线，角度差数字（如 `23° apart at release`）--看你和顶尖的差距
- **对标自己**：你今天 + 你那次最好的出手，角度差数字（如 `9° from your best`）--看你离自己的最佳有多远（个人基准模板）

**关键：** 没有这一段，"看不见的差距"只是嘴上说了，没让观众看见。Proof 让 Guide 的"我看得见"有了证据闭环。视频里用圈选高亮 + 度数砸数字。

### 6. SUCCESS - 成功的愿景

**SB7 角色：** 描绘成功后的世界。不是"产品能做什么"，是"你修掉差距后会怎样"。

> **When the power flows, the shot goes.**
>
> 发力通了，球就进了。不是运气。不是更多练习。只是一个差距被找到、被修掉。这就是"感觉不对"和"空心入网"的区别--你终于找回了那次"感觉对了"。

**不是功能描述，是成功后的世界：** 用户买的不是"角度分析"，是"出手那一刻，你知道它会进"--因为你看过了那次感觉对的曲线，你知道这一次和它一样。

**CTA（Success）：** `Find your gap -> formrefine.ai`（换词避免和 Hero 的 CTA 重复感）

### 7. CTA 重复策略（散落各段，3-5 次）

SB7 强调 CTA 要出现 3-5 次。各段 CTA：

| 位置 | CTA 文案 | 类型 |
|------|---------|------|
| Hero | `See your gap` | 过渡 |
| Plan 段末 | `See your gap` | 直接 |
| Success 段 | `Find your gap` | 直接（换词） |
| 社媒 bio / 结尾卡 | `formrefine.ai` | 品牌 |

**结尾卡 CTA：** 视频 outro 的 wordmark 屏 `formrefine.ai` + tagline `Feel the difference you can't see.`

## 功能实现：个人基准模板（"感觉对了的那次"作为基准）

品牌叙事里"把你最好的那次存成模板反复对比"依赖**个人模板功能**。实现状态（2026-07 已完成）：

| 层 | 状态 |
|----|------|
| 数据库 `user_templates` 表 + `frame_data`/`phases`/`has_curve_data` 列 | ✅ |
| `db_service`：create / get / delete user_template + `get_user_template_curves`（带所有权校验） | ✅ |
| `GET /users/templates`（列出个人模板） | ✅ |
| `POST /users/templates/from-analysis`（从分析结果创建含曲线的个人模板） | ✅ |
| 个人模板存**曲线数据**（frame_data + phases） | ✅ |
| 前端"存为我的基准"按钮（分析结果页，登录可见） | ✅ |
| 分析时选个人模板做曲线对比（upload.py 双路：admin/user，template_source 参数） | ✅ |
| 前端模板选择下拉分组（Pro Templates / My Baselines） | ✅ |

**设计要点：**
- 曲线存表（`user_templates.frame_data`），不存文件，继承 RLS 权限隔离，规避 results 目录 auto-delete 风险。
- 对比链路双路并存：admin 模板走原 `template_manager` 文件路径，user 模板走 `db_service.get_user_template_curves` 表路径，共用 `compare_curves()` 纯函数。
- 个人模板对比主打**曲线**，关键帧并排对比降级（comparisons 为空）--品牌叙事核心是曲线量化。
- 文案已从"愿景语气"升级为交付承诺，Proof 段"对标自己"（`9° from your best`）已启用。

**待办（非阻塞）：** 个人模板的删除 UI（template-modal 管理弹窗暂未加 My Baselines 标签页，用户暂无法在前端删除旧基准）。

**Why 记录：** 品牌叙事和产品功能已对齐，避免 SB7 向导承诺给不了的东西（信任崩塌）。

## 视频统一结尾卡（Outro Card - 两屏版）

每条视频结尾复用，约 2.5s，分两屏。先 tagline 压一拍情绪，再 formrefine.ai 做品牌落定。

### 时间结构

```
12.5–13.7s  Screen 1  tagline: Feel the difference you can't see.
13.7–15.0s  Screen 2  wordmark: formrefine.ai
```

> 要从转折段借 1.5s 给结尾（转折段压到 1.5s，放 2–3 个改进镜头快剪）。

### Screen 1 - tagline 屏（12.5–13.7s）

```
┌─────────────────────────┐
│                         │
│   Feel the difference   │  <- Montserrat Regular，白色 90%
│   you can't see.        │  <- 双行，第二行延迟 0.25s
│                         │
└─────────────────────────┘
```

### Screen 2 - wordmark 屏（13.7–15.0s）

```
┌─────────────────────────┐
│                         │
│      formrefine.ai      │  <- Montserrat SemiBold，纯白
│      ─────────────      │  <- 下划线绘制动画（可选，加分项）
│      Free to try.       │  <- 小字，降低行动门槛
│                         │
└─────────────────────────┘
```

### 贯穿两屏的规则

- **背景不断**：深海军蓝 #0A1A2F 从 Screen 1 起到 Screen 2 末，不换底色
- **字重对比做主次**：tagline 用 Regular（轻），wordmark 用 SemiBold（重），靠字重告诉观众哪个是主角
- **接力感**：tagline 淡出（13.5s 起 0.2s）与 wordmark 淡入（13.7s 起 0.3s）有 0.1s 重叠，不要硬切
- **chime 落在 wordmark 出现，不落在 tagline** -- 印章才需要声音盖章

### 声音设计

- **Screen 1（12.5s）**：低频 pad / sustain 长音，音量 40%，给 tagline 屏悬浮感，不抢戏
- **Screen 2（13.7s）**：双音 chime（低 -> 高），第一个音对齐 wordmark 出现，第二个音对齐下划线画完（14.5s）
- **BGM** 在 14.5s 加淡出 0.5s，让 chime 成为最后被听到的声音

### 审美规则

- 不要描边、阴影、发光 -- 静态权威感，干净字号字重对比就够了
- 单独渲染成一个 2.5s 片段，后续每条视频直接拼接

## 文案调性规则（写新文案时遵循）

1. **不说"analyze"** -- 太工具感。用"find / see / feel"这种带感知的动词。
2. **保留体感词** -- "feels off / flow / smooth / rhythm" 这类打球人真用的词，比 "kinetic chain / power disconnect" 这种术语更亲用户（术语留给产品内部）。
3. **是邀请不是陈述** -- "Find out why" 比 "We analyze your shot" 强，因为前者把用户放主语。
4. **英文为主** -- 面向海外用户（参见 [[video-series-formrefine]]）。
5. **短** -- 视频里的字越少越好，slogan 也尽量一句能读完。
6. **顾客是英雄，品牌是向导** -- SB7 核心原则。文案主语永远是用户（"your shot / your gap / you"），不是产品（"our AI / we analyze"）。
