# 第 4 条视频脚本 - 工具录屏 + 字幕版（轻量制作）

**总时长：** 45 秒（推荐剪辑版）/ 65 秒（原始素材完整版）\
**画幅：** 9:16 竖屏（由横屏录屏放大/裁剪中间区域，或保持横屏发 YouTube Shorts）\
**语言：** 英文字幕 + 英文 on-screen text，旁白/说明用中文\
**制作工具：** CapCut / 剪映，只加字幕 + BGM，不做过渡特效\

---

## 为什么这条更简单

前几条脚本（video-script-03.md）需要实拍分镜、调色、音效、多段素材剪辑。\
这条脚本基于你已经录好的 **一次完整工具使用录屏**，只需要：

1. 剪掉多余的等待/加载空白
2. 加上英文字幕
3. 加一段简单的背景音乐
4. 结尾接统一品牌卡

> 核心卖点不变：**把"感觉不对"量化成角度和曲线**。

## 按画面内容配字幕（不依赖固定时间点）

如果你的剪辑和 45 秒推荐版不完全一致，用下面这张表对照画面事件来放字幕。

| 画面事件 | 英文字幕 | 建议停留时长 |
|---------|---------|------------|
| 原始投篮视频开始播放 | That shot went in. | 2–3 秒 |
| 球进后 / 准备切到 app | But something felt off. | 1–2 秒 |
| 退出全屏，回到 formrefine 上传界面 | So I uploaded it to formrefine.ai. | 2–3 秒 |
| 鼠标点击「Start Analysis」/ 按钮显示 Analyzing | It tracks 33 body points frame by frame. | 3–4 秒 |
| 进度条显示 Detecting pose landmarks → Generating key frames → Analysis complete | Then maps every joint angle. | 2–3 秒 |
| 结果页出现 Key Shooting Frames 网格 | The curve shows what my eyes missed. | 2–3 秒 |
| 滚动到 / 出现 Angle Curves 曲线图 | | |
| Power Coordination：Hand-Foot Sync ✓ Good | Hand-foot sync: good. | 2–3 秒 |
| Power Coordination：Power Disconnect ⚠ Minor Issue | But my hand rose before my leg finished pushing. | 3–4 秒 |
| Power Disconnect 解释文字出现 | That's why the power felt disconnected. | 2–3 秒 |
| Suggestion 建议文字出现 | Now I know what to fix. | 2–3 秒 |
| 结尾品牌卡 | Film. See. Fix. formrefine.ai | 3 秒 |

### 对齐关键规则

1. **「But something felt off.」** 放在 raw shot 结束、但 app 界面还没完全出来之前，作为转折。
2. **「It tracks 33 body points...」** 从「Start Analysis」按钮被点击那一刻开始，可以横跨整个进度条阶段。
3. **「The curve shows what my eyes missed.」** 要在 Angle Curves 曲线图第一次完全出现时出现，不要停留在 Key Frames 阶段。
4. **「Hand-foot sync: good.」** 和 **「But my hand rose...」** 是核心反差，确保在 Power Coordination 区域完全可见时再出现。
5. **「Now I know what to fix.」** 放在 Suggestion 文字出现时，作为情绪收尾。

## On-Screen Text 设计

- **字体：** 无衬线粗体（Inter / Montserrat / 剪映默认粗体）
- **位置：** 画面下方 1/4 处，不要遮挡关键帧和曲线
- **颜色：**
  - 正常叙述：白色 `#FFFFFF` + 黑色描边
  - 发现问题：黄色 `#feca57`（你的品牌用户色）
  - 结论/CTA：青色 `#48dbfb`（AI 数据色）
- **动画：** 淡入淡出即可，不要弹跳/缩放

---

## 音乐与音效

**推荐风格：**
- 前半段（0:00–0:20）：低能量 lo-fi / ambient，略带悬疑感
- 后半段（0:20–0:45）：加入轻微鼓点，营造"找到答案"的释放感

**音效（可选，极简）：**
- 0:00 投篮出手：很轻的一声 net swish（如果原视频有，保留）
- 0:14 结果出现：一个轻微的 "pop" 或 "chime"
- 0:42 CTA：无音效，让品牌卡干净收尾

> 也可以全程只用 BGM，不加任何音效。保持"工具感"。
